PROJECT / 03

Smart Medication System

Smart Medication Dispensing System with Wearable-Assisted Alerts and Real-Time Monitoring

SMART MEDICATION

IOT / WEARABLE SYSTEM

Connecting medication reminders with wearable technology.

The Smart Medication System is an IoT-based project exploring a medication dispensing system combined with wearable-assisted alerts and real-time monitoring.

ESP32 IoT Wearable

01 / OVERVIEW

The idea behind the project.

Bringing medication reminders closer to the user.

The project explores the development of a smart medication dispensing system that can provide scheduled medication reminders while working alongside a wearable device.

The system combines embedded hardware, wireless connectivity, and wearable-assisted notifications to create a more connected medication management experience.

02 / THE CONCEPT

A system built around reminders.

The main device handles medication-related functions while the wearable provides another way to receive alerts.

Instead of relying solely on a medication dispenser to notify the user, the project explores how a wearable device can extend the reminder system.

This creates a system where information and alerts can be delivered through connected devices rather than remaining limited to a single hardware unit.

04 / HARDWARE

Built around ESP32.

Embedded hardware connects the medication system and wearable device.

ESP32 ESP32-C3 Super Mini Wearable Device Wireless Connectivity Battery Power

05 / DEVELOPMENT

Connecting hardware and software.

The project focuses on the interaction between the medication device and wearable.

Development involves working with ESP32-based hardware, wireless communication, power management, and wearable device integration.

The wearable component is intended to provide another channel for medication-related alerts, allowing notifications to reach the user through a portable device.

06 / STATUS

Research and development project.

Exploring the intersection of IoT, embedded systems, and wearables.

The Smart Medication System is a research and development project focused on exploring how connected embedded devices and wearable technology can work together for medication reminders and monitoring.
