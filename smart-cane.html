Smart Assistive Cane

Smart Assistive Cane for Safety and Reminder System

SMART CANE

EMBEDDED SYSTEM

Making an ordinary cane smarter.

The Smart Assistive Cane is an Arduino-based assistive device designed to combine safety, reminder, monitoring, and convenience features into a single portable system.

Arduino OLED Sensors

01 / OVERVIEW

The idea behind the project.

Combining multiple assistive functions into one handheld device.

The project explores how embedded systems can be integrated into an everyday mobility aid to provide additional safety and convenience features.

An Arduino Nano acts as the main controller, communicating with sensors, a display, audio output, buttons, and other components integrated into the cane.

02 / FEATURES

What the system can do.

Reminders

Time-Based Reminders RTC Scheduling Audio Notifications

Monitoring

Step Counting Motion Detection Real-Time Display

Safety

Low-Light Detection Automatic Lighting Motion-Based Monitoring

User Interface

OLED Display Physical Buttons Audio Feedback

03 / HARDWARE

Built with.

An Arduino-based system combining sensors, displays, and peripheral modules.

Arduino Nano OLED SH1106G DS3231 RTC MPU6050 LDR DFPlayer Mini Push Buttons LED 18650 Battery TP4056

04 / SYSTEM DETAILS

How the components work together.

Sensors collect information while the Arduino processes it and provides feedback.

The MPU6050 provides motion information that can be used for movement-related functions such as step counting.

The DS3231 real-time clock provides accurate time information for reminder functions.

The LDR detects surrounding light levels, allowing the system to respond to darker environments with an LED.

The OLED provides visual information to the user, while the DFPlayer Mini can provide audio feedback or reminder sounds.

05 / DEVELOPMENT

Building the system.

Hardware integration was the core challenge of the project.

The project involves integrating multiple modules with the Arduino Nano while managing their communication, power requirements, and software logic.

Components communicate through interfaces such as I²C, while buttons and other modules are connected through dedicated digital and analog inputs.

06 / STATUS

Hardware project in development.

From individual modules to an integrated assistive system.

The Smart Assistive Cane is a hands-on embedded systems project focused on combining multiple hardware components into a functional prototype.
